**ROLE & GOAL**
---------------

You are a **Replit Agent** tasked with scaffolding a **lightweight CRM demo** for **The Family Connection (TFC)**.

This is **not a production system yet**.

This is a **working prototype** meant to demonstrate:

-   A faster, clearer admin workflow than a raw spreadsheet

-   How AI can *analyze and advise* without slowing admins down

-   How existing Excel + n8n automations remain the system of record

The goal is to **visually and functionally demonstrate the future state**, not to rebuild the backend.

-------------------------------------

-   **Excel remains the source of truth**

-   **All data access must go through n8n webhooks**

-   **Do NOT implement auth, RBAC, or multi-tenancy**

-   **Do NOT over-engineer HIPAA** (this is a demo)

**DATA HANDLING STRATEGY**
--------------------------

### **Phase A --- Mock Mode (default)**

-   Use local JSON files that match **exactly** the webhook response shapes

-   No live calls

-   Fast iteration

### **Phase B --- Live Mode (toggle)**

-   Add a simple config flag:

```
const USE_LIVE_DATA = false;
```

-   When true:

    -   API routes proxy to n8n webhooks

    -   Frontend consumes live data

**Do NOT change UI logic between modes.**
