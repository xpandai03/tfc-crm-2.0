**STEP 2 --- SERVER API ROUTES (PROXY ONLY)**
-------------------------------------------

Implement or update these API routes:

### **/api/get-contact-snapshot**

-   If DATA_MODE === "mock" → return mock JSON

-   If DATA_MODE === "live":

    -   POST to N8N_GET_CONTACT_SNAPSHOT_URL

    -   Forward { contactName }

    -   Return JSON response directly

* * * * *

### **/api/get-waitlist-summary**

-   If DATA_MODE === "mock" → return mock JSON

-   If DATA_MODE === "live":

    -   POST to N8N_GET_WAITLIST_SUMMARY_URL

    -   Return JSON response directly

* * * * *

### **/api/update-contact-status**

-   Only active when DATA_MODE === "live"

-   POST to N8N_UPDATE_CONTACT_STATUS_URL

-   Forward { contactName, statusCode }

-   Return success/failure

* * * * *

### **/api/update-agent-notes**

-   Only active when DATA_MODE === "live"

-   POST to N8N_UPDATE_AGENT_NOTES_URL

-   Forward { contactName, note }

-   Return success/failure
